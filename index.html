LAN games

These four need a tiny Python server as the referee, so they can't run from a static page. Clone the repo, start the server, and everyone on the same Wi-Fi plays.

🏓 Neon Pong Showdown

LAN · :3000

Power-up Pong: expand, shrink, turbo, slow, shield and freeze. Spin shots, overdrive, sudden death. Play 2P over LAN or solo vs AI.

Run python3 server.py in hybrid1-2/neon-pong/, then open the printed URL on both devices.

🤖 Tank Duel

LAN · :3001

Maze tanks on a fresh symmetric map every round. Shells ricochet six times, weapon pickups, railguns, homing shells and mines. First to 5 rounds.

Run python3 server.py in 2players/tank-duel/, then open the printed URL on both devices.

How to run

💣 Bomb Tag

LAN · :3002

Hot potato in an arena. One ticks, both run — tag to pass it. The holder is slower, dash has a 3s cooldown, fuse is 8–14s. First to 5 blasts.

Run python3 server.py in 2players/bomb-tag/, then open the printed URL on both devices.

🛰️ Echo Hunt

LAN · :3003

Sonar tag for 2–8. Wardens hunt on a near-black screen; Divers crack wire nodes. Roles rotate, terror radius, and the host can add AI bots.

Run python3 server.py in 2players/echo-hunt/, then open the printed URL on both devices.

How to run
