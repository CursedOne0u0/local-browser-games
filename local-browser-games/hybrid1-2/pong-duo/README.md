# Pong Duo — Solo or 2P Same Keyboard 🏓

![Gameplay](screenshot.png)

One file, two modes picked from the menu:

- 🤖 **1 Player** — you (left, `W`/`S` or mouse) vs AI with Easy / Medium / Hard.
- 👥 **2 Players** — P1 `W`/`S` vs P2 `↑`/`↓` on one keyboard, touch uses screen halves.

First to 7. `Space` launches / pauses, `M` mutes.

## Run

Just open `index.html` (or `./start-linux.sh` / `start-windows.bat`). No server needed.
