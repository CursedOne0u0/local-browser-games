# Swarm Survival — Co-op Arena 🛸

Top-down co-op arena survival: move + autofire only. Solo, solo + AI
companion, or 2P local. Survive 50s waves, draft upgrades between waves,
bomb the swarm when it closes in, and revive your partner when they go down.

Just open `index.html`. No server needed.

Controls: P1 `WASD` + `E` bomb · P2 `←↑↓→` + `/` bomb · draft `1/2/3` (P1) and `7/8/9` (P2) · `Space` start · `P`/`Esc` pause · `M` mute · touch halves · dual gamepads.
